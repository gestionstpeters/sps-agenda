      Google Drive — Archivos adjuntos
      Sube los adjuntos de las actividades directamente a tu Drive
      Se crea en Google Cloud Console → APIs y servicios → Credenciales → ID de cliente OAuth (tipo Aplicación web). Agrega este dominio en "Orígenes autorizados de JavaScript".
      La app crea esta carpeta automáticamente en tu Drive la primera vez que subas un archivo.
      ⚠️ Al conectar, inicia sesión con la cuenta gestion@stpeters.cl (la misma usada para el envío de correos) para que los adjuntos queden centralizados ahí.
      Cómo obtener el Client ID:
      1. Ve a console.cloud.google.com → crea o selecciona un proyecto
      2. Habilita la Google Drive API
      3. Ve a Credenciales → Crear credenciales → ID de cliente de OAuth → tipo "Aplicación web"
      4. En "Orígenes de JavaScript autorizados" agrega la URL desde donde abres esta app
      5. Copia el Client ID generado y pégalo arriba
      ✨ Groq IA — Importar PDF
      Analiza PDFs con inteligencia artificial usando Groq (gratis, sin restricciones de Workspace)
      Se obtiene gratis en console.groq.com con cualquier correo personal (Gmail, Outlook, etc.). No requiere tarjeta de crédito.
      Cómo obtener la API Key gratuita (5 minutos):
      1. Ve a console.groq.com
      2. Regístrate con cualquier correo personal (no necesita ser Google)
      3. Ve a API Keys → "Create API Key"
      4. Copia la key generada (comienza con gsk_) y pégala arriba
      5. Guarda — el botón "📄 Importar PDF" usará IA automáticamente
